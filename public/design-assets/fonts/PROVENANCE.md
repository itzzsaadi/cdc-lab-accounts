# Font provenance — locally hosted, no Google Fonts runtime/build-time request

Both fonts are served entirely from this repository via `next/font/local`
(`src/lib/fonts.ts`). Neither the built application nor the build process
makes any request to `fonts.googleapis.com`/`fonts.gstatic.com` or any other
external font/icon host — per the approved Phase 3A decision, this
supersedes the `next/font/google` approach considered during planning.

## How these were obtained

Both files were fetched via `npm pack` against the public npm registry
(`@fontsource/inter@5.3.0`, `@fontsource/material-symbols-outlined@5.3.3`),
then the specific `.woff2` files and each package's own `LICENSE` file were
extracted and copied here. **Neither package is a project dependency** —
`package.json` lists no `@fontsource/*` entry; only the static font/license
files were kept, satisfying the "no new dependency" preference (`CLAUDE.md`
§24) while still sourcing the binaries from a reliably-versioned,
checksummable, properly-licensed distribution channel rather than an
un-versioned direct download.
