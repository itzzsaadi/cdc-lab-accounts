## `public/design-assets/` status

**Empty (placeholder `.gitkeep` only).** Nothing in the handoff qualifies as a bundled, locally-hostable image/icon/font file — every visual asset besides the screenshots and `DESIGN.md` is either a live external font/icon request or an external placeholder photo, both flagged above as not suitable to copy in as-is. When real, licensed static assets are chosen (a real font file, a real icon package, real avatar handling), they belong here.

## Summary

- **2** bundled, self-hosted font files as of Phase 3A (Inter, Material Symbols Outlined — both `public/design-assets/fonts/`); **0** bundled image files.
- **0** external font/icon dependencies remaining — **resolved in Phase 3A**: both Inter and Material Symbols Outlined are now self-hosted via `next/font/local`, vendored from `@fontsource` (npm) with their OFL-1.1 licenses kept alongside the font files. See `public/design-assets/fonts/PROVENANCE.md` for exact source, version, and checksums, and `docs/adr/0004-phase-3a-shared-shell.md` for the design record.
- **9** external placeholder avatar photos — **approved decision: not used.** Replaced by a neutral initials-based `Avatar` component, built in Phase 3A (`src/components/ui/Avatar.tsx`).
- **1** external script (Tailwind CDN) that must never reach production.
- **0** broken references among the files actually delivered in the handoff.

## Approved decisions affecting this inventory

See `docs/UI_REQUIREMENTS.md` §1 for the full record. The one directly relevant here: the Administrator Profile placeholder avatar photos are confirmed **not** to be used in production, resolving what was previously an open licensing question — Phase 3A built the initials-based replacement this decision calls for.

## Phase 3A resolution note

The font offline-hosting question this document originally flagged as open ("before Phase 6") was resolved earlier, in Phase 3A, not deferred to Phase 6 — self-hosting via `next/font/local` was straightforward enough, and reusable enough across every future screen's icons, that there was no reason to wait. Both fonts are vendored as static `.woff2` files with their licenses and a provenance record (source, version, checksum) — see `public/design-assets/fonts/PROVENANCE.md`.
